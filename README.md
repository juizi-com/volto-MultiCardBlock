# volto-MultiCardBlock

> [!IMPORTANT]
> **This block has moved.** It is now part of [juizi-blocks](https://github.com/juizi-com/juizi-blocks), Juizi's consolidated block set for Plone 6 and Volto, which is actively maintained (currently in alpha). This repository is no longer updated.
>
> In juizi-blocks this block is the **Content Row** block, using its card or statistics display style. Content built with this older block is converted automatically when a page loads; see [COMPATIBILITY.md](https://github.com/juizi-com/juizi-blocks/blob/main/COMPATIBILITY.md).

A block to define a number of cards, where each card defines a background image, text and button. Editors can define number of columns available on desktop (max 5) and text alignment.
